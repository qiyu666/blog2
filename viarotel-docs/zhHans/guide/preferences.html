主题配置 ​

站点配置 ​

在 config.mts 中配置站点基本信息：

ts
export default defineConfig({
  title: '我的博客',
  description: '记录学习与生活',
  lang: 'zh-CN',
  lastUpdated: true,
  cleanUrls: true,
})

导航栏配置 ​

ts
themeConfig: {
  nav: [
    { text: '首页', link: '/' },
    { text: '技术', link: '/tech/' },
    { text: '生活', link: '/life/' },
    {
      text: '更多',
      items: [
        { text: '关于', link: '/about' },
        { text: 'GitHub', link: 'https://github.com' }
      ]
    }
  ]
}

侧边栏配置 ​

ts
sidebar: {
  '/tech/': [
    {
      text: '技术文章',
      items: [
        { text: 'Vue', link: '/tech/vue' },
        { text: 'React', link: '/tech/react' }
      ]
    }
  ]
}

自定义主题色 ​

在 docs/.vitepress/theme/ 下创建自定义 CSS：

css
:root {
  --vp-c-brand: #ff6600;
  --vp-c-brand-light: #ff8533;
  --vp-c-brand-dark: #cc5200;
}

社交链接 ​

ts
socialLinks: [
  { icon: 'github', link: 'https://github.com/yourname' },
  { icon: 'twitter', link: 'https://twitter.com/yourname' }
]

搜索功能 ​

ts
search: {
  provider: 'local'
}
